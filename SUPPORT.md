# Getting help

Moment is made by volunteers in their own time. Here is where to go.

| You want to | Go to |
|---|---|
| Install Moment, or move to a new version | [README → Install](README.md#install) |
| Know what changed in a version | [CHANGELOG.md](CHANGELOG.md) |
| Know what Moment does with your data | [The privacy policy](https://saranmahadev.github.io/Moment/privacy.html), and About in the app |
| Report something that does not work | [Open a bug report](https://github.com/saranmahadev/Moment/issues/new?template=bug_report.yml) |
| Suggest an idea | [Open a feature request](https://github.com/saranmahadev/Moment/issues/new?template=feature_request.yml) |
| Report a security or privacy problem | Privately, as [SECURITY.md](SECURITY.md) says. Not in a public issue. |
| Help build Moment | [CONTRIBUTING.md](CONTRIBUTING.md) |

## Before you open an issue

- Search the [existing issues](https://github.com/saranmahadev/Moment/issues?q=is%3Aissue), open and closed.
- Say which version you use (Settings → Version) and which phone and Android version.
- If the app misbehaves, Settings → Diagnostics holds a short log of errors. It never contains what you wrote, but read it before you share it.
- **Never paste your journal entries, photos, recordings, places or backups into an issue.** Nobody needs them to help you.

## What we cannot do

Moment has no servers and no accounts, so nobody can recover a lost backup passphrase or a journal from a lost phone. Keep a recent backup somewhere safe.
